# Spectrum 🧩💙

> Um ambiente digital inclusivo focado no apoio, desenvolvimento e conexão para a comunidade autista.

### 📄 Sobre o Projeto

O **Spectrum** é uma aplicação web desenvolvida para oferecer suporte integral a pessoas no Espectro Autista. O objetivo é criar um ecossistema seguro que une acompanhamento profissional, desenvolvimento cognitivo e apoio comunitário.

Este projeto nasceu de uma parceria interdisciplinar no **Senac**. A turma de **Administração** idealizou o modelo de negócio e a marca "Spectrum", e eu fui responsável pelo desenvolvimento técnico (Front-end), transformando a ideia em um site funcional.

### ✨ Funcionalidades

O site é dividido em cinco pilares principais:

* 🔐 **Sistema de Autenticação:**
    * Cadastro e Login funcionais, com armazenamento de credenciais (e-mail e senha) por meio do LocalStorage do navegador, para simular um banco de dados e persistir os dados do usuário.
    * Segurança de acesso para proteger a área do usuário.
* 👤 **Perfil e Configurações:**
    * Área de gerenciamento onde é possível editar dados pessoais (nome de usuário, e-mail e senha).
    * **Suporte Inteligente:** Um Chatbot (robô de atendimento) integrado na aba de perfil para tirar dúvidas e oferecer ajuda.
* 🩺 **Conexão com Especialistas:** Uma área dedicada para encontrar e conectar-se com médicos e terapeutas especializados no atendimento ao público autista.
* 🧠 **Desenvolvimento Cognitivo & Emocional:**
    * **Jogos Interativos:** Quebra-cabeça e Jogo da Memória desenvolvidos para incentivar a capacidade cognitiva de forma lúdica.
    * **Diário de Emoções:** Uma ferramenta para auxiliar no reconhecimento e registro de sentimentos diários.
* 💬 **Comunidade e Social:**
    * **Comunidade Spectrum:** Um espaço social onde usuários podem entrar em grupos temáticos para compartilhar experiências, dúvidas e conquistas em um ambiente seguro.
    * **Aba de Eventos:** Divulgação de encontros e atividades (simulação/fictícios).
    * **Central de Notificações:** Para manter o usuário atualizado sobre interações e novidades.
